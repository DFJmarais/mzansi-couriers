# iOS App Store Submission Checklist: Mzansi Couriers

Use this checklist to track your progress through the App Store submission process.

## 1. Apple Developer Account Setup
- [ ] Enrolled in Apple Developer Program
- [ ] Two-Factor Authentication enabled for Apple ID
- [ ] Financial information (tax, banking) set up in App Store Connect

## 2. App Preparation (Assets & Information)
- [ ] App Icon (1024x1024 PNG)
- [ ] 5 Professional Screenshots (1440x2560 for 6.9-inch iPhone)
- [ ] App Name
- [ ] Primary Language
- [ ] Primary Category
- [ ] Bundle ID (e.g., `com.mzansicouriers.app`)
- [ ] Version Number (e.g., `1.0.0`)
- [ ] Copyright (e.g., `2026 Mzansi Couriers`)
- [ ] Privacy Policy URL (`https://mzansicouriers.com/privacy`)
- [ ] Support URL (`https://mzansicouriers.com/support`)
- [ ] Marketing URL (Optional)
- [ ] Compelling App Description (up to 4000 characters)
- [ ] Keywords (up to 100 characters, comma-separated)
- [ ] App Review Contact Information
- [ ] Demo Account (if app requires login)
- [ ] Notes for App Review team (if any)
- [ ] Pricing and Availability selected

## 3. Create App in App Store Connect
- [ ] Logged in to App Store Connect
- [ ] Navigated to "My Apps"
- [ ] Added New App
- [ ] Filled in App Details (Platforms, Name, Language, Bundle ID, Version, SKU)

## 4. Prepare for Submission in App Store Connect
- [ ] App Information (Category, Content Rights, Age Rating)
- [ ] Pricing and Availability (Price Tier, Availability)
- [ ] App Privacy (Privacy Policy URL, Data Collection questions answered)
- [ ] App Store Tab:
    - [ ] Screenshots uploaded
    - [ ] Promotional Text (Optional)
    - [ ] Description entered
    - [ ] Keywords entered
    - [ ] Support URL entered
    - [ ] Marketing URL entered (Optional)
    - [ ] Build selected (after Xcode upload)
    - [ ] App Review Information provided

## 5. Build and Archive Your App (Xcode)
- [ ] Project opened in Xcode
- [ ] Version and Build Numbers updated
- [ ] Signing & Capabilities configured (Automatic signing, Team selected, Bundle ID matches)
- [ ] "Generic iOS Device" selected
- [ ] App Archived (Product > Archive)
- [ ] App Distributed (Distribute App > App Store Connect)

## 6. Submit for Review
- [ ] Build selected in App Store Connect
- [ ] All information reviewed
- [ ] Submitted for Review

## 7. App Review Process
- [ ] App status monitored (Waiting for Review, In Review, Approved/Rejected)
- [ ] If rejected, addressed issues and resubmitted

## 8. Release Your App
- [ ] If manual release, clicked "Release Your App" after approval

## 9. Post-Launch Monitoring
- [ ] Monitoring performance via App Store Connect Analytics
- [ ] Responding to reviews
- [ ] Planning future updates
