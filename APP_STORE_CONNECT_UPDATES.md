# App Store Connect Updates - Step by Step

**Your app is uploaded! Now update the metadata.**

---

## Step 1: Go to App Store Connect

1. Click: **"Show in App Store Connect"** (from the upload dialog)
2. Or go to: https://appstoreconnect.apple.com
3. Sign in with your Apple ID
4. Click: **"My Apps"**
5. Select: **"Mzansi Couriers"**

---

## Step 2: Update App Icon

1. Click: **"App Information"** (left menu)
2. Scroll down to: **"App Icon"**
3. Click on the current icon
4. Click: **"Choose File"**
5. Select: **mzansi-app-icon.png**
6. Click: **"Save"** (top right)

**Wait for it to save** (you'll see a checkmark)

---

## Step 3: Update Screenshots

1. Click: **"Previews and Screenshots"** (left menu)
2. For **iPhone**:
   - Delete all old screenshots
   - Click: **"Add Screenshot"**
   - Upload: **appstore-screenshot-1-home.webp**
   - Upload: **appstore-screenshot-2-pricing.webp**
   - Upload: **appstore-screenshot-3-service-levels.webp**
3. For **iPad** (if you have iPad screenshots):
   - Do the same for iPad section
4. Click: **"Save"** (top right)

**Wait for it to save**

---

## Step 4: Update Privacy Information

1. Click: **"App Privacy"** (left menu)
2. Click: **"Edit"**
3. When asked "Does this app collect user data?":
   - Select: **"Yes"**
   - Click: **"Next"**
4. Click: **"Add Data Type"**
5. Add these data types:
   - **Location Data** (check: "Linked to user identity" ✓)
   - **User ID** (check: "Linked to user identity" ✓)
   - **Email Address** (check: "Linked to user identity" ✓)
   - **Purchase History** (check: "Linked to user identity" ✓)
6. Click: **"Save"** (top right)

---

## Step 5: Add Review Notes

1. Click: **"Version Information"** (left menu)
2. Scroll down to: **"Review Notes"**
3. Click in the text box
4. Copy-paste this:

```
We've fixed all issues from the previous rejection:

1. App Crash: Enhanced error handling and WebView initialization to prevent crashes on launch
2. Metadata: Updated app icon and screenshots with actual app functionality
3. Privacy: Implemented App Tracking Transparency (ATT) permission request
4. Stability: Improved error logging and crash prevention

The app now:
- Launches without errors on all iOS 14+ devices
- Requests user permission for tracking via ATT framework
- Displays accurate app metadata and screenshots
- Has comprehensive error handling and logging

All changes comply with Apple's privacy and app completeness guidelines.
```

5. Click: **"Save"** (top right)

---

## Step 6: Submit for Review

1. Look for: **"Submit for Review"** button (usually at top right)
2. Click it
3. A dialog appears asking about compliance:
   - Answer the questions (usually "No" for most)
   - Click: **"Submit"**
4. You'll see: **"Your app has been submitted for review"**

---

## ✅ Done!

Your app is now submitted! 🎉

**What happens next:**
- Apple reviews your app (24-48 hours)
- You get an email: either "Approved!" or "Rejected"
- If approved, it appears on the App Store!
